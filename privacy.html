Privacy policy

Last updated: 9 October 2026

What it can access

otp-reader asks Google for read-only Gmail access (gmail.readonly). It is used with a single Gmail account that I own.

What it does with that access

It searches for verification code emails from a few specific senders and reads the code out of them. It does not read other mail for any other purpose, and it never sends, changes or deletes mail.

What is kept

The access token is stored encrypted on my own server. Email contents are not saved. A code is only held in memory until it has been used.

Sharing

Nothing is sold or shared with anyone. No data is sent to third parties.

Google API data

otp-reader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from your Google Account permissions page.
